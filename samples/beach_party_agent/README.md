# Beach Party Planner Agent

This sample demonstrates a simple A2A agent that provides a basic beach party plan.

## Requirements

- Python 3.10+
- `a2a-sdk`

Install dependencies:

```bash
pip install a2a-sdk
```

## Running the Agent

```bash
python -m samples.beach_party_agent
```

The agent starts a server on `http://localhost:9999/`.

## Testing

Run tests with `pytest`:

```bash
pytest tests/test_beach_party_agent.py
```
